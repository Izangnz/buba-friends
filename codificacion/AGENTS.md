# Instrucciones de Buba Friends

- Trabaja únicamente en este proyecto; no modifiques Mi Progreso Diario ni otros proyectos.
- Antes de cada bloque importante, inspecciona el estado y guarda una versión local de recuperación en Git sin sobrescribir el historial existente. Si falta una identidad explícita o hay un impedimento, comunícalo y conserva una copia local identificada del código mientras se resuelve. No inventes identidades.
- Al finalizar cada bloque y comprobarlo, guarda otra versión local de recuperación. Distingue los commits de las copias de archivos y documenta cualquier comprobación pendiente.
- No incluyas secretos, credenciales, datos personales, almacenamiento del navegador ni archivos sensibles en el historial o las copias. Añade archivos revisados de forma explícita; no publiques ni hagas push sin autorización.
- Mantén la demo sencilla, las ilustraciones propias y la compatibilidad del guardado. Las pruebas con DOM simulado no sustituyen una revisión visual en navegador.
