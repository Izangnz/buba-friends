# Escenas originales de ejemplo

Tres ilustraciones vectoriales originales dibujadas en SVG para Buba Friends:

- `gallery.svg`: exposición pequeña; historia de ejemplo de Vega.
- `trail.svg`: sendero y paisaje; historia de ejemplo de Nico.
- `music.svg`: guitarra, escenario y luces; historia de ejemplo de Alma.

No usan fotografías, retratos del catálogo, recursos externos ni referencias a personas reales. No son imágenes subidas por el usuario. Los tres SVG se incluyen en el paquete, pero esta documentación no. Las fechas, vistas y caducidad se guardan en IndexedDB; no están incrustadas en estos archivos.
